# M4 · 加载 OBJ 模型与线框渲染

> **里程碑**：渲染器第一次由外部数据驱动——顶点不再写死在代码里，而是从一个模型文件读进来。
> 前置：[M0](M0-环境搭建.md) ｜ [M1](M1-画布与BMP输出.md) ｜ [M2](M2-向量矩阵与线段绘制.md) ｜ [M3](M3-三角形填充.md)
> 逐行讲解版：[M4 详解](M4-加载OBJ模型与线框渲染-详解.md)

## 目标

把外部三维模型读进程序，投影到画布上画出来。这一节引入四件事：

1. **`Vec3`**：三维向量类型。
2. **OBJ 文件解析**：文本模型格式的读取与容错。
3. **三维旋转**：`Mat3` 扩展出绕 x / y / z 三轴的旋转。
4. **投影与归一化**：把三维坐标落到二维画布上，并自动适配尺寸。

## 成果

![M4 载入模型的线框渲染](images/m4-model-wireframe.png)

从 `assets/cube.obj` 载入（8 顶点 / 12 三角形），绕 x 轴 −20°、绕 y 轴 30° 旋转后正交投影到画布，自动缩放到占画布 90%。

图中可见的对角线是**三角形网格的固有外观**：每个四边形面在三角化时会产生一条被两个三角形共享的对角线，而线框会把每个三角形的三条边都画出来。六条对角线分别汇聚到立方体空间对角线的两个端点上。M5 把这些三角形填充成实心面后，它们就会隐入面内。

## 实现

### 1. `Vec3`（`src/Vec3.h`）

与 `Vec2` 同构：加减、标量乘、点积、长度、单位化，成员函数一律加 `const`。

这一次没有把 `Vec2` 与 `Vec3` 合并成模板 `Vec<N>`：两个类型加起来不到八十行，可读性比抽象更值钱。抽象的时机是"重复开始带来真实痛苦"的时候。

### 2. 三维旋转（`src/Mat3.cpp`）

| 变换 | 矩阵特征 |
| --- | --- |
| `rotationX` | 第 0 行保持 `1 0 0`，旋转部分在右下 2×2 子块 |
| `rotationY` | 第 1 行保持 `0 1 0` |
| `rotationZ` | 第 2 行保持 `0 0 1`，等价于原先的 `rotation` |

同时新增 `transformVector(Mat3, Vec3)`：**不补齐次坐标的 1，也不做 w 除法**。因为向量不受平移影响，而点会——这个区分以后变换法线时是必需的。

### 3. OBJ 解析（`src/model.h` / `src/model.cpp`）

`Model` 就是两张表：

```cpp
std::vector<Vec3> vertices;   // 顶点表
std::vector<Face> faces;      // 面表，每个面存三个索引
```

解析采用"三层"结构：`ifstream`（文件）→ `std::getline`（行）→ `std::istringstream`（单词）。只处理 `v` 与 `f` 两种标记，其余（`#`、`vn`、`vt`、空行）自然跳过。

三个必须处理的细节：

- **索引从 1 开始计数**，读入后减 1；
- **一个面可以有任意多个顶点**，用扇形拆分转成三角形；
- **索引可能写成 `1/2/3` 的形式**，只取斜杠之前的顶点索引。

### 4. 投影与归一化

- **正交投影**：旋转后直接取 `(x, y)`，忽略 z（透视投影在 M6）；
- **y 取反**：模型空间 y 向上，画布 y 向下；
- **归一化**：先扫描所有顶点求出投影后的包围盒，再算出等比缩放（取横竖两个比例中较小者）与平移，使模型居中且占画布 90%；
- **退化保护**：包围盒宽或高为 0 时直接返回，避免除零。

## OBJ 格式速查

| 标记 | 含义 |
| --- | --- |
| `#` | 注释 |
| `v x y z` | 顶点坐标 |
| `f a b c ...` | 面，索引从 **1** 开始 |
| `f 1/2/3 ...` | 顶点 / 纹理 / 法线索引，只取第一段 |
| `vn` / `vt` | 法线 / 纹理坐标（M4 未使用） |

面顶点的排列顺序（**绕序**）表示正面朝向：从物体外面看应当是逆时针。M4 只画线框还看不出来，M5 的背面剔除与 M8 的光照都会依赖它。

## 坐标约定

| 空间 | 约定 |
| --- | --- |
| 模型空间 | 右手坐标系：x 向右、y 向上、z 朝向观察者 |
| 画布 | 原点左上、x 向右、**y 向下** |

两者 y 方向相反，所以投影时把 y 取反。这是 M2 埋下的"y 向下"第一次真正收利息。

## 验证方式

| 测试 | 结果 |
| --- | --- |
| `Vec3` 长度 / 点积 / 单位化 | `5 / 5 / 12 / (0, 0.6, 0.8) / 1` |
| 三轴各旋转 90° | 方向符合右手定则（含 `6.12e-17` 级浮点残差） |
| `cube.obj` | 8 顶点 / 12 面，索引校验通过 |
| `test_quad.obj`（四边形面） | 4 顶点 / **2** 面，三角化正确 |

| 不存在的路径 | 加载被拒绝 |

## 踩坑记录

| 现象 | 根因 |
| --- | --- |
| 模型文件提交不上去 | `.gitignore` 里的 `*.obj`（微软目标文件扩展名）把模型一起挡住了，需要加 `!assets/*.obj` 例外 |
| 加载失败 | `assets/cube.obj` 是相对路径，相对的是**当前工作目录**，必须先 `cd` 到仓库根目录再运行 |
| 图形上下颠倒 | 忘了把模型空间的 y 取反 |
| 模型大得看不见或小成一个点 | 缩放写死，需要按包围盒归一化 |
